# Decisión UX/comercial — Hero emocional + promociones dinámicas

Fecha: 2026-08-24

## Decisión
- Mantener un hero emocional permanente de Trhoncal Travel.
- El hero usa imágenes de destinos públicos con derechos verificados desde el Archivo Maestro; no depende de una promo de proveedor para verse atractivo.
- Las promociones dinámicas aparecen como franja/carrusel complementario cuando existen ofertas públicas vigentes.
- Una promoción puede mostrar sólo destino, precio o precio-desde, vigencia y CTA.
- El enlace externo directo al proveedor sólo se habilita cuando el enlace está expresamente autorizado para cliente y conserva la relación/comisión de Trhoncal. En caso contrario, el CTA se queda en Trhoncal (WhatsApp/cotización).
- Los enlaces públicos normales de PriceTravel no se usarán automáticamente como CTA de venta de Trhoncal.

## Motivo
PriceTravel opera como canal directo al consumidor y sus promociones tienen vigencias, disponibilidad, restricciones y a veces canales específicos. PriceAgencies es la plataforma B2B para agentes y declara comisiones, personalización y enlaces de pago/cliente. La web debe evitar desintermediación y mantener trazabilidad comercial.

## Regla de publicación
Oferta pública = Mostrar_Web + Publicable + Vigente + precio reconfirmado + no expirada.
Enlace externo = además requiere autorización explícita de enlace de cliente/agencia.
