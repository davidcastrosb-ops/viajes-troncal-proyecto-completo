# Trhoncal Travel — SOP de Venta

## Objetivo
Que cada solicitud siga el mismo camino y pueda migrarse a Kommo sin rediseñar la operación.

## Etapas
1. **Lead recibido**
   - Se registra en `13_Solicitudes_Web` con folio TT.
   - Canal/origen/UTM deben conservarse.
   - Tiempo objetivo de primera respuesta: definir antes de campañas pagadas.

2. **Contacto inicial**
   - Confirmar destino o intención.
   - Confirmar ciudad de salida, fechas, viajeros y presupuesto aproximado cuando sea necesario.
   - No pedir documentos sensibles en esta etapa.

3. **Cotización**
   - Consultar proveedor vigente.
   - Verificar precio, inventario, impuestos, ocupación, plan y política de cancelación.
   - Registrar fecha/hora de reconfirmación.
   - Presentar 1–3 opciones relevantes, evitando saturar.

4. **Interés / decisión**
   - Identificar opción elegida.
   - Reconfirmar proveedor antes de pago.
   - Entregar condiciones y vigencia de la cotización.

5. **Contratación / pago**
   - Utilizar únicamente el medio de cobro autorizado para esa operación.
   - Conservar comprobante.
   - No marcar como reservado hasta obtener confirmación real del proveedor.

6. **Confirmación**
   - Guardar número de reserva/localizador.
   - Entregar voucher/documentos aplicables.
   - Registrar proveedor, política aplicable y contacto de soporte.

7. **Previaje**
   - Recordatorio de fechas, horarios y documentación.
   - Para internacional: reconfirmar requisitos mediante fuentes oficiales vigentes.

8. **Durante el viaje**
   - Registrar cualquier incidencia con folio.
   - Escalar con el proveedor y documentar respuesta.

9. **Postviaje**
   - Confirmar cierre.
   - Solicitar retroalimentación/reseña cuando proceda.
   - Registrar resultado y margen real.

## Estados propuestos para futuro pipeline Kommo
- Nuevo
- Contactado
- Calificado
- Cotizando
- Cotización enviada
- Decisión pendiente
- Pago en proceso
- Reservado / confirmado
- En viaje
- Cerrado ganado
- Cerrado perdido
- Incidencia

## Regla de oro
La web puede inspirar y mostrar un precio confirmado recientemente, pero **la venta siempre reconfirma precio, disponibilidad y condiciones antes de cualquier compromiso final**.
